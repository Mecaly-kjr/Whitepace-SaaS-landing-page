# 🏷 Whitepace SaaS Landing Page

A responsive SaaS landing page that showcases project management, team collaboration, pricing plans and productivity features.

---

## 📌 Problem Statement

Many teams and businesses need a simple and organised way to manage projects, collaborate and improve productivity. However, presenting these services clearly online is important for attracting users and explaining the value of a product.

This project recreates the Whitepace SaaS landing page to demonstrate a modern, responsive and user-friendly website using HTML and CSS.

---

## 🎯 Project Goals

- Recreate the Whitepace landing page from the provided Figma design.
- Build all sections from the header to the footer.
- Create responsive layouts for mobile, tablet and desktop.
- Present project management and collaboration features.
- Display three pricing plans.
- Showcase sponsors, app integrations and customer testimonials.
- Practise semantic HTML and modern CSS layouts.

## ⚙ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Mecaly-kjr/Whitepace-SaaS-landing-page.git
```

Navigate into the project folder:

```bash
cd Whitepace-SaaS-landing-page
```

Open the project in Visual Studio Code:

```bash
code .
```

Run the project:

Open `index.html` in your browser or use the Live Server extension in VS Code.

No dependencies or installation packages are required.
